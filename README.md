## ✨ About the Project

Job hunting can get messy when applications, interview dates, and follow-ups are spread across different places.

**CareerTrack** brings that information together in one dashboard. Add applications, update their status, search your records, and keep track of your progress — all without needing an account or a backend.

## 🚀 Features

| Feature | Description |
|---|---|
| 📊 **Dashboard** | Get an overview of applications, interviews, offers, and rejections. |
| ➕ **Application Management** | Add, edit, and delete job application records. |
| 🔄 **Status Tracking** | Track Applied, Interview, Offer, Rejected, and Withdrawn applications. |
| 🔎 **Search & Filter** | Quickly find applications and filter them by status. |
| ↕️ **Sorting** | Sort by date, company name, and upcoming follow-ups. |
| 📝 **Application Notes** | Store useful notes for each opportunity. |
| 💾 **Persistent Storage** | Keep records saved in browser local storage after refreshing. |
| 📱 **Responsive Layout** | Use the dashboard on desktop and smaller screens. |

## 🛠️ Built With

- **HTML5** — page structure
- **CSS3** — styling and responsive layout
- **Vanilla JavaScript** — application logic and DOM manipulation
- **localStorage** — browser-based data persistence

No frameworks or external dependencies are required.

## 💻 Getting Started

1. Clone the repository:

2. Open the project folder:

   ```bash
   cd job-application-tracker
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## 💾 Data & Privacy

CareerTrack stores application records in your browser using `localStorage`.

- No backend or account is required.
- Data is stored locally in the browser and is not automatically synced across devices.
- Clearing browser storage may remove saved records.
